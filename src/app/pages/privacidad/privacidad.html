2. Datos que se pueden tratar

Este sitio web no dispone de registro de usuarios, área privada, sistema de login, formularios de alta ni cuentas personales. La navegación por la web no exige facilitar datos personales.

Panthera Project solo podrá tratar los datos que la persona usuaria facilite voluntariamente al contactar por WhatsApp, teléfono, email, redes sociales u otros medios habilitados.

Estos datos pueden incluir nombre, número de teléfono, usuario de redes sociales, dirección de correo electrónico, mensaje enviado y cualquier otra información que la persona usuaria decida comunicar.

3. Finalidad del tratamiento

Los datos personales facilitados voluntariamente se tratarán únicamente para responder consultas, atender solicitudes de información y gestionar la comunicación iniciada por la persona usuaria.

No se crean perfiles de usuario, no se venden datos personales y no se utilizan los datos para finalidades distintas a la atención de la solicitud recibida, salvo que se informe previamente y exista una base jurídica adecuada.

4. Base jurídica

La base jurídica para el tratamiento de los datos será, según corresponda, el consentimiento de la persona interesada al contactar voluntariamente, la aplicación de medidas precontractuales o contractuales solicitadas por la persona usuaria y/o el interés legítimo en atender las comunicaciones recibidas.

5. Conservación de los datos

Los datos se conservarán durante el tiempo necesario para atender la solicitud, mantener la relación profesional o cumplir posibles obligaciones legales. Una vez dejen de ser necesarios, se eliminarán o bloquearán conforme a la normativa aplicable.

6. Comunicación de datos a terceros

No se cederán datos personales a terceros salvo obligación legal o cuando sea necesario para prestar un servicio solicitado por la persona usuaria.

El sitio web puede incluir enlaces a plataformas externas como Instagram, WhatsApp u otras marcas colaboradoras. El uso de dichas plataformas estará sujeto a sus propias políticas de privacidad.

7. Derechos de las personas usuarias

La persona usuaria puede ejercer sus derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad, cuando proceda, escribiendo a: juliapantera2025@gmail.com.

También puede presentar una reclamación ante la Agencia Española de Protección de Datos si considera que el tratamiento de sus datos no se ajusta a la normativa aplicable.

8. Seguridad

Panthera Project aplicará medidas razonables para proteger los datos personales frente a accesos no autorizados, pérdida, uso indebido o divulgación no autorizada.

9. Cambios en la política de privacidad

Panthera Project podrá modificar esta política de privacidad para adaptarla a cambios legales, técnicos o de funcionamiento del sitio web. La versión vigente será la publicada en esta página.
